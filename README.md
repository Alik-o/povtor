# Проект виджет для банка

Создает маску для карты или счета клиента, также фильтрует транзакции и сортирует по дате и статусу.

## Расположение

Скачать репозиторий проекта можно по ссылке [GitHub](https://github.com/Alik-o/povtor.git)

## Тестирование

Для запуска тестов используйте команду `pytest`
